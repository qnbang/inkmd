# inkmd

가장 가벼운 맥용 마크다운 메모 편집기. Electron 없이 순수 SwiftUI/AppKit으로 만든 400KB 미만 앱.

왼쪽엔 진짜 컴퓨터 폴더 트리(볼트·DB 개념 없음), 오른쪽엔 마크다운 기호가 보이지 않는 편집 화면.
파일은 순수 `.md` 텍스트로 저장돼 git·다른 도구와 그대로 호환된다.

## 왜 inkmd

| | inkmd | Typora | Obsidian |
|---|---|---|---|
| 설치 크기 | **< 0.4 MB** | ~90 MB | ~250 MB |
| 런타임 | **네이티브 AppKit** | Electron | Electron |
| 저장 방식 | 순수 `.md` 폴더 | `.md` | 볼트 |

대부분의 마크다운 앱은 텍스트를 렌더링하려고 브라우저 엔진을 통째로 싣는다.
inkmd는 맥에 이미 들어있는 네이티브 텍스트 엔진만 쓴다.

## 기능

- 폴더 트리(중첩 그대로) · 새 파일(⌘N) · 폴더 열기(⇧⌘O)
- 파일명 더블클릭 또는 엔터로 인라인 이름변경, 우클릭 삭제(휴지통)
- 마크다운 기호(`#`, `**`, `` ` ``)는 화면에서 숨김 — 서식만 보임
- 표준 제목 크기(본문 대비 제목 2.0× · 부제목 1.5× · 소제목 1.25×)
- 리스트 자동 이어쓰기: `- `·`1. ` 뒤 엔터 → 다음 항목 자동, 빈 항목 엔터 → 리스트 종료
- 숫자만 치고 스페이스 → 자동으로 번호 리스트 시작, 항목은 탭 한 칸 들여쓰기 (아이폰 메모 방식)
- 서식 단축키: 제목 ⌘1 · 부제목 ⌘2 · 소제목 ⌘3 · 본문 ⌘0 · 글머리 ⇧⌘8 · 굵게 ⌘B · 기울임 ⌘I
- 실행취소 ⌘Z · 다시실행 ⇧⌘Z · 찾기 ⌘F · 저장 ⌘S
- 다른 파일로 넘어갈 때 자동저장

## 설치

[릴리스](../../releases/latest)에서 `inkmd.zip`을 받아 압축을 풀고 `inkmd.app`을 실행한다.

> Apple 노터라이제이션이 안 된 애드혹 서명 앱이라, 처음 열 때 "확인되지 않은 개발자" 경고가 뜬다.
> **우클릭 → 열기**로 한 번 허용하면 이후 정상.

## 직접 빌드

```sh
swift build -c release
bash 앱만들기.sh      # → ~/Applications/inkmd.app
```

macOS 14+ · Swift 5.9+
